- Closet scanner placeholder tagging

- Caption generator

### Implemented technical details

#### Image capture

- Camera source supported
- Gallery source supported
- Preview shown before upload

#### Image compression

- Compression occurs before upload
- Max width: `1080`
- JPEG format
- Quality: `70`

#### Storage upload

- Unique ID generated by UUID
- Path used: `clothing_items/{uuid}.jpg`
- Download URL retrieved after upload

#### Firestore metadata

Collection: `clothing_items`

Fields written:

- `id` (String)
- `category` = `shirt`
- `status` = `clean`
- `imageUrl` (String)
- `createdAt` = `FieldValue.serverTimestamp()`

#### Dashboard listing

- `StreamBuilder` used
- `GridView` with 2 columns
- `Image.network` for image display
- Ordered by `createdAt` descending
- Limit set to `50`
- States handled:
  - Loading spinner
  - Empty message (`No items yet`)
  - Error message

#### Upload screen states

- Pick actions (camera/gallery)
- Upload action
- Loading indicator while uploading
- Success/error messages via snack bars

#### Permissions

- Camera permission requested
- Gallery/photo/storage permissions requested
- Denied permissions handled with clear message
